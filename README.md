# ¿Qué es GitHub?
**GitHub** es una plataforma basada en la nube que permite a los desarrolladores almacenar, compartir y colaborar en proyectos de software. Utiliza
**Git**, un sistema de control de versiones, para gestionar los cambios en el código y facilitar el trabajo en equipo. Fue lanzada en 2008 y adquirida por Microsoft en 2018.
En GitHub, los proyectos se organizan en **repositorios**, que pueden ser públicos o privados. Estos repositorios contienen el código fuente, documentación y otros archivos relacionados con el proyecto. Además, GitHub ofrece herramientas para la colaboración, como **pull requests**, **issues** y **wikis**, que permiten a los equipos trabajar de manera eficiente.
## Principales características de GitHub
- **Control de versiones**: GitHub utiliza Git para rastrear y gestionar los cambios en el código, permitiendo a los desarrolladores trabajar en diferentes ramas sin afectar la versión principal.
- **Colaboración en equipo**: Facilita la revisión de código, la discusión de cambios y la asignación de tareas mediante herramientas como pull requests e issues.
- **Automatización**: Con **GitHub Actions**, se pueden configurar flujos de trabajo automatizados para pruebas, despliegues y más.
- **GitHub Pages**: Permite alojar sitios web estáticos directamente desde un repositorio, ideal para portafolios o documentación.
- **Integraciones**: Es compatible con herramientas como Jira, Trello y Slack para mejorar la gestión de proyectos.
## Diferencias entre Git y GitHub
Aunque están relacionados, **Git** y **GitHub** no son lo mismo. Git es una herramienta de control de versiones que se instala localmente para gestionar el historial de cambios de un proyecto. Por otro lado, **GitHub** es una plataforma en línea que utiliza Git para alojar repositorios y agregar funcionalidades adicionales, como colaboración y automatización.
## ¿Por qué usar GitHub?
GitHub es esencial para desarrolladores porque permite un **control eficiente de versiones**, facilita la **colaboración en tiempo real** y actúa como una **red social profesional** para programadores. Además, su capacidad de automatización y su integración con otras herramientas lo convierten en una solución completa para gestionar proyectos de software.
